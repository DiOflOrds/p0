# Requirements — P0 "Genesis" Platform

*Owner: RM. Language: English (D011). First real SWE.1 set (Sprint 2, T-0021): the requirements for the team's own platform.*

**Structure:** `stakeholder/` — stakeholder requirements (STK-xxx, SYS.1 share); `software/` — software requirements (SWR-xxx, SWE.1) with traceability to STK.

**Status model per requirement:** `draft` → `reviewed` (feasibility + verifiability + QM check passed) → `baselined` (G1, tag by CM). Changes to baselined requirements only via change request (SUP.10).

**DoD per software requirement** (Playbook ch. 6, checklist `process/checklists/dod-sw-anforderung.md`): unique ID; unambiguous, atomic, verifiable wording ("shall"); attributes complete (source, priority, status); trace to STK; verification criterion stated.
